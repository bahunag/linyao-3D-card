# 林爻3D贺卡（`linyao-3D-card` · V8.6）

专为**自带看图与生图能力的多模态 AI 助手（千问、豆包、Antigravity 等）**打造的 3D 立体贺卡定制技能包，支持 **生日 / 圣诞双主题** 与 **上下翻折 4:3 横向长方形 / 左右横版双版式**。

> **安装说明**：不论在何种 AI 平台安装，中文展示名称统一为 **`林爻3D贺卡`**（技能标识 `linyao-3d-card`，仓库/包名 `linyao-3D-card`）。

## 设计目标与核心特点
- **极致轻量纯文本，云端直装不卡壳**：仅包含 **7 个核心纯文本文件**（总明文约 `91 KB`，标准 ZIP 约 `42 KB`，**全文件 0 反斜杠**彻底消除 JSON 转义纠结，内置 2 批防截断装包指引；零外部二进制大图、零联网脚本、零 API 密钥）。
- **4:3 上下翻折大气立体比例（跨模型恒定）**：拱门自动撑满至整张贺卡宽度的 `94%`（左右各仅留约 1 厘米精致纸边，并内置瘦高拱门补宽兜底），中央人物同步放大近 2 倍稳居正中 C 位，前排蛋糕与蜡封信封拉开清晰纵深，无论使用强弱模型出图均保持大气舒展构图。
- **纯前景 100% 精准蜡烛定位（零误伤白奶油蛋糕）**：`scripts/pack_card.py` 在加 300g 米白卡纸刀模边前直接保留纯主体前景遮罩（对已带刀模边的透明图采用外缘 15px 受限剥离），配合顶部最高峰与中轴居中加权精准锁定顶部单蜡烛黑棉芯；蛋糕重绘提示词彻底移除木椅/花环干扰物。
- **暖沙原麻 3D 高度场棉麻刺绣信本地实时合成**：纯 Pillow 现场织出带斜粒微纹理、云斑揉皱、厚鼓滚边凹槽、手工斜倾粗白棉绳锁边与手撕短棉絮的亚麻底布（520×710，零外部大图），支持手机端全层滑动编辑与超长文布内滚动。
- **真人友好双通道吹蜡烛 + 预览壳无打扰体验**：
  - 两段式零穿模 3D 纸艺与防破音三层谐波机械八音盒（生日《生日快乐歌》/ 圣诞《We Wish You a Merry Christmas》）；
  - 独立网页打开时自动启用双通道宽带 SFM 吹气引擎（`65~680Hz` 主力贴麦低中频气流 + `950~3600Hz` 高通麦呼气，对数 dB 加法门槛，抗音乐和弦/180Hz 嗡声/空调底噪误触）并配实时跳动音量条；
  - 在千问分享壳等未开放麦克风的嵌套预览中自动跳过无效授权弹窗，零技术词打扰，直接温和引导 **“长按蜡烛吹灭许愿”**（长按 1 秒带风声吹灭与花瓣特效）；
  - 圣诞树 Alpha 实体内芯防悬空常亮闪烁星灯 + 点击星光绽放飘雪。
